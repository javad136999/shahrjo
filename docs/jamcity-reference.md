# مرجع JamCity برای ShahrJo

بررسی از `javad136999/jamcity` (clone موقت در `.jamcity-ref/` — هرگز commit نمی‌شود).
**قانون: فقط منطق و تجربه کاربری بازطراحی می‌شود؛ کد عیناً کپی نمی‌شود.**
Stack JamCity: Next.js 14 + Supabase (Auth/DB/RLS) + Leaflet + Tailwind + PWA —
همه وابستگی‌های Supabase باید حذف و با Backend مستقل ShahrJo جایگزین شوند.

## ۲. ترتیب بخش‌های صفحه اصلی شهر (الگوی UX قابل حفظ)

1. کارت هدر **«دیوار شهر {city}»** (hero گرادیانی + CTA ورود به دیوار)
2. **«ویترین طلایی کنار دیوار»** — نوار افقی infinite-loop از کسب‌وکارهای Gold با 👑،
   کارت فشرده: نام + لوگو + ⭐ + پیش‌نمایش اولین محصول + لینک صفحه کسب‌وکار
3. فیلتر دسته‌بندی (select) + **نقشه** با markerهای رنگی (tier + rating)
4. **«کسب‌وکارهای طلایی»** — گروه‌های محصول طلایی per دسته (اتوگالری، املاک،
   لوازم خانگی، رستوران، کافه + سایر) با اسکرول افقی
5. **«تخفیف‌های داغ»** — نوار محصولات دارای `discount_percent` با badge درصد
6. **«محبوب‌ها»** — top رتبه‌بندی (`rating_avg` با `rating_count>0`)
7. بنر CTA دیوار + **آمار** (تعداد کسب‌وکار / طلایی / تخفیف فعال) + خوش‌آمد
8. جستجوی قیمت بازار (torob) در مودال — اختیاری

> نکات: RTL، همه تصاویر `loading="lazy"`، کارت‌ها با پالت رنگ شهر، drag-to-scroll
> روی نوارها، ایموجی به‌عنوان fallback آواتار/لوگو.

## ۳. Gold / Silver (منطق واقعی JamCity)

- ستون‌های `businesses`: `subscription_tier ∈ {bronze, silver, gold}`،
  `subscription_status ∈ {pending, approved, rejected}` + ایندکس روی هر دو.
  (پرداختِ درون‌برنامه‌ای ندارد؛ کارت به کارت دستی — ShahrJo: **زرین‌پال**.)
- قیمت‌ها و امکانات (از `lib/constants.ts` — قیمت به تومان، ShahrJo به ریال):

| Tier | ۱ ماهه | ۶ ماهه | ۱۲ ماهه | امکانات |
|---|---|---|---|---|
| 🥇 Gold | ۴۰۰k | ۱٫۵M | ۲٫۵M | ویترین طلایی صفحه اصلی، انتشار روزانه آگهی در دیوار، منوی تخفیف‌ها، منوی محبوب‌ها، نشان طلایی، مدیریت کامل منو/محصولات، نقشه شهر، کلیپ تبلیغاتی |
| 🥈 Silver | ۲۰۰k | ۸۰۰k | ۱٫۳M | نقشه، مدیریت منو/محصولات، تخفیف‌ها، محبوب‌ها، کلیپ |

- **ترتیب ویترین طلایی**: اولویت گروه دسته (`GOLD_PRIORITY_GROUPS`):
  اتوگالری → گروه خرده‌فروشی (پوشاک، کفش، آرایشی، طلافروشی، موبایل،
  کامپیوتر، الکترونیک، لوازم خانگی، مبلمان، سوپرمارکت، میوه، قصابی، نانوایی، فروشگاه)
  → املاک؛ به‌علاوه **چرخش روزانه** (queue های `wall_republish`).
  ShahrJo: `showcasePriority` (ادمین) + تای‌بریک `subscriptionExpiresAt/createdAt`.

## ۵. سایر قابلیت‌هایی که باید حفظ شوند

دیوار شهر (پست با دسته، لایک، وضعیت خواندن، republish روزانه از کاربران متفاوت) ·
محصولات/منوی کسب‌وکار با `discount_percent` · امتیازدهی (`business_ratings`) ·
گزارش/بان (`reports`) · نوتیفیکیشن push (`push_subscriptions`) · اخبار + cron ·
معرفی دوستان · رویدادها · چت خصوصی · آمار بازدید (`site_visits`) ·
چندشهری ( Jam + Kangan در مایگریشن‌ها) · emoji avatar · recovery phrase.

## ۶. تفاوت‌های اجباری ShahrJo

1. **Auth**: OTP پیامکی بدون Password (پیاده‌شده در Phase 2).
2. **Payment**: زرین‌پال با Callback+Verify و تأیید ادمین قبل از فعال‌سازی اشتراک.
3. **بدون Supabase**: همه RPS/Trigger/Storage آن‌ها → NestJS + Prisma + StorageService.
4. Multi-City از روز اول: `city_id` روی همه رکوردهای شهرمحور.
